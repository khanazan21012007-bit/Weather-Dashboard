AuraWeather 
A modern, responsive weather dashboard web application built with vanilla HTML, CSS, and JavaScript. It features a stunning glassmorphism aesthetic, dark/light theme switching, live data tracking via the Open Meteo API, geolocation support, and recent search history saved via LocalStorage.

Features
Live Weather Search: Real-time search for any city or location globally using the Open-Meteo Geocoding & Weather APIs.

Geolocation Integration: Fetch weather instantly for your current location with a single click.

Glassmorphic UI & Animations: Beautiful modern glassmorphism aesthetic complete with dynamic floating background orbs and smooth transitions.

Dark & Light Theme Toggle: Seamless switching between dark and light modes with persistent preference or responsive styling.

Recent Searches History: Quick access chips for your recently searched cities, powered by browser localStorage.

Fully Responsive Design: Optimized layout that adapts smoothly across mobile phones, tablets, and desktop displays.

🛠️ Tech Stack
HTML5: Semantic markup structure.

CSS3: Custom properties (CSS variables), Flexbox, CSS Grid, backdrop filters, and keyframe animations.

JavaScript (ES6+): Asynchronous API handling (async/await), DOM manipulation, and Geolocation/LocalStorage APIs.

APIs:

Open-Meteo Geocoding API

Open-Meteo Weather Forecast API

Assets & Icons: Google Fonts (Outfit) and Google Material Icons Round.

 Getting Started
To run this project locally on your machine, follow these simple steps:

Clone or Download this repository.

Ensure you have the following three files in the same directory:

index.html

Style.css

Script.js

Open index.html directly in any modern web browser (Chrome, Firefox, Edge, Safari), or run it using a local development server like Live Server in Visual Studio Code.
